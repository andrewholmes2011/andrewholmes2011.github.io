Before connecting

  1. Configure a Cloudflare Tunnel to reach the Windows computer.
  2. Protect the remote desktop application with Cloudflare Access and allow only your own verified account.
  3. Use a supported Windows edition with Remote Desktop hosting enabled.
  4. Keep Windows sign-in enabled and do not expose Remote Desktop directly through your router.

Security note: this public GitHub Pages file must never contain passwords, access tokens, tunnel credentials, or private keys. Authentication belongs at the remote-access gateway, not in this page.
