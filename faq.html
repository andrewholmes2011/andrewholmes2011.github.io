Technology FAQ

Clear, beginner-friendly answers to common questions about technology, computers, software, security, and the web.

Software & web

What is the difference between HTML, CSS, and JavaScript?

HTML provides the structure of a page, CSS controls its appearance, and JavaScript adds behavior and interaction.

What should I do when an app stops responding?

Save any work you can, close and reopen the app, restart the device if needed, and check for updates. Avoid downloading “fixes” from untrusted websites.

What is a backup?

A backup is an extra copy of important data stored somewhere separate from the original. Keep more than one copy when possible and test that you can restore it.

Security & hardware

How can I make an account more secure?

Use a unique password, turn on multi-factor authentication, keep recovery details current, and never share verification codes.

Why are updates important?

Updates can add features, improve stability, and fix security weaknesses. Use official update tools and keep your operating system and important apps current.

What is troubleshooting?

Troubleshooting is a methodical process: describe the problem, check simple causes, change one thing at a time, test the result, and record what worked.
