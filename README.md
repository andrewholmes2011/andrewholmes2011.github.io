# Andrew Holmes Website

This repository is organized by purpose. The main website remains at the repository root so the homepage and primary navigation keep their existing URLs.

## Sections

- `/screens/` — screensavers and full-screen clock displays.
- `/media/` — media projects, including slideshows, music, and display pages.
  - `/media/slideshows/` — slideshow pages and printout version.
  - `/media/music/` — music page.
  - `/media/displays/` — display page.
- `/tools/` — interactive utilities and web tools, including the resume maker and remote access page.
- `/school/` — school-related pages and projects.
  - `/school/apcyber/` — AP Cybersecurity feedback page.
- `/flp/` — Financial Literacy Portfolio. This section was already organized and remains self-contained.

## Main website pages

The homepage, FAQ, directory, resources, downloads, resume, contact, and search pages remain in the root because they are part of the site's main navigation and use shared root-level assets.

## Compatibility

The previous root-level URLs for moved pages remain as small redirects to their new locations. This keeps older bookmarks and links working while the organized copies live in their section folders.
